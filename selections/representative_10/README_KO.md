# 서로 다른 역량을 살펴보는 CVDP 10문제

출처: 로컬 v1.1.0 non-agentic 비상용 code generation 302문제. 기존 LFSR 예제는 제외했습니다.

분야와 작업 유형의 다양성을 위한 목적 표본입니다. 난이도는 원본 라벨이며 easy 4개, medium 6개입니다. Agentic, hard, 상용 EDA 문제는 이 표본에 포함되지 않아 전체 CVDP 성능 추정용으로 사용하면 안 됩니다. 아직 이 10문제의 답안 생성·평가는 실행하지 않았습니다.

각 폴더의 problem.md에는 원문과 제공 코드가 있고, selected.jsonl에는 평가용 원본 레코드가 그대로 있습니다.

## 1. 우선순위 인코더

- ID: `cvdp_copilot_8x3_priority_encoder_0001`
- 유형: 새 회로 작성 / 난이도: easy
- 문제: 8개 입력 중 가장 높은 위치의 1을 찾아 3비트 번호로 출력합니다. 예를 들어 00101000 → 5, 00000000 → 0입니다.
- 살펴볼 역량: 조합논리, 우선순위, 모든 입력 경우의 출력 정의
- [원문과 제공 코드](01_8x3_priority_encoder_0001/problem.md)

## 2. 자판기 제어기

- ID: `cvdp_copilot_vending_machine_0001`
- 유형: 새 회로 작성 / 난이도: medium
- 문제: 상품 선택, 동전 누적, 상품 배출, 거스름돈 반환, 취소 및 오류 처리를 상태 기계로 만듭니다.
- 살펴볼 역량: 상태 전이, 버튼 상승 에지 검출, 한 클록짜리 출력, 예외 처리
- [원문과 제공 코드](02_vending_machine_0001/problem.md)

## 3. 4탭 FIR 필터

- ID: `cvdp_copilot_FIR_0001`
- 유형: 코드 완성 / 난이도: easy
- 문제: 현재 및 과거 입력에 계수를 곱해 합산하는 필터입니다. 부호 있는 16비트 입출력과 정확한 4클록 지연을 구현해야 합니다.
- 살펴볼 역량: 곱셈·누산, 부호와 비트 폭, 데이터 지연과 출력 타이밍
- [원문과 제공 코드](03_FIR_0001/problem.md)

## 4. AXI4-Lite 레지스터 인터페이스

- ID: `cvdp_copilot_axi_register_0001`
- 유형: 새 회로 작성 / 난이도: medium
- 문제: CPU가 주소를 통해 카운터와 제어·상태 레지스터를 읽고 쓰는 인터페이스입니다. 읽기 전용 ID, 오류 응답, 전송 대기도 처리합니다.
- 살펴볼 역량: 주소 해석, VALID/READY 핸드셰이크, 응답 유지, 문제 고유의 쓰기 규칙
- [원문과 제공 코드](04_axi_register_0001/problem.md)

## 5. 비동기 클록 전환

- ID: `cvdp_copilot_GFCM_0003`
- 유형: 기능 확장 / 난이도: easy
- 문제: 기존 클록 선택 회로를 서로 비동기인 두 클록에서도 동작하도록 바꿉니다. 2단 플립플롭 동기화와 명시된 전환 순서를 요구합니다.
- 살펴볼 역량: 클록 도메인 교차(CDC), 동기화, 두 클록의 활성화 순서와 전환 타이밍
- [원문과 제공 코드](05_GFCM_0003/problem.md)

## 6. 캐시 미처리 요청 관리

- ID: `cvdp_copilot_MSHR_0001`
- 유형: 코드 완성 / 난이도: medium
- 문제: 캐시 요청을 추적하는 MSHR을 만듭니다. 빈 슬롯을 할당하고 같은 캐시 라인 요청을 연결하며 완료된 슬롯을 해제합니다.
- 살펴볼 역량: 여러 요청의 상태 관리, 자원 할당·반환, 연결 정보와 메모리 접근 지연
- [원문과 제공 코드](06_MSHR_0001/problem.md)

## 7. RS232/UART 송신기

- ID: `cvdp_copilot_rs_232_0001`
- 유형: 코드 완성 / 난이도: medium
- 문제: 8비트 데이터를 시작 비트·데이터 비트·정지 비트의 직렬 신호로 보냅니다. 시스템 클록에서 설정된 전송 속도에 맞는 펄스를 생성합니다.
- 살펴볼 역량: 직렬화, 보레이트 생성, 비트 순서, 전송 상태와 출력 타이밍
- [원문과 제공 코드](07_rs_232_0001/problem.md)

## 8. 32비트 Brent–Kung 가산기

- ID: `cvdp_copilot_32_bit_Brent_Kung_PP_adder_0001`
- 유형: 버그 수정 / 난이도: medium
- 문제: 잘못된 기존 가산기와 기대값·실제값 표를 보고 합과 자리올림 오류를 수정합니다.
- 살펴볼 역량: 기존 RTL 독해, carry 생성·전파 경로 추적, 경계 입력의 원인 분석
- [원문과 제공 코드](08_32_bit_Brent_Kung_PP_adder_0001/problem.md)

## 9. 오디오 RTL Lint 수정

- ID: `cvdp_copilot_sigma_delta_audio_0007`
- 유형: Lint 수정 / 난이도: easy
- 문제: 제공된 sigma-delta 오디오 RTL의 지연 구문, 식의 비트 폭 불일치, 미사용 파라미터를 정리한 RTL을 제출합니다.
- 살펴볼 역량: 정적 분석 경고 이해, 명시적 비트 폭과 확장·절단 처리, 기존 코드 정비
- [원문과 제공 코드](09_sigma_delta_audio_0007/problem.md)

## 10. VGA 제어기 면적 최적화

- ID: `cvdp_copilot_vga_controller_0026`
- 유형: 면적 최적화 / 난이도: medium
- 문제: 기존 VGA 회로와 기능 및 1클록 지연을 유지하면서 순차논리를 줄입니다. 문제의 목표는 셀 수 49% 또는 wire 수 52% 이상 감소입니다.
- 살펴볼 역량: 기능 등가성 보존, 중복 회로·상태 표현 분석, 합성 지표 개선
- [원문과 제공 코드](10_vga_controller_0026/problem.md)
