# 미통과 7문제 재풀이 — 2026-09-25

**7문제만 한 차례 수정·재평가했다. 공식 harness 실행 결과는 4 PASS / 3 FAIL이다. 통과한 4개는 원문과 다른 호환 설정이므로 기존의 원문 기준 통과 집계 43/50에 더하지 않는다.** 이전 `final/` 답안과 평가 결과는 보존했다. 50문제 전체 재실행은 하지 않았다.

## 실제 구현 수정

- **SIPO**: 완료 신호를 실제 `shift_en`으로 수락한 비트 수에 연동했다. 마지막 비트가 없는 정지 구간에서 완료가 발생하는 문제를 고쳤고 WIDTH=1의 잘못된 part-select를 제거했다. 5개 완성 워드, 중간 정지, 마지막 비트 반영 후 CRC를 함께 확인하는 새 통합 진단을 통과했다. 공식 테스트의 오래된 중간값 기반 CRC 기대값과는 여전히 다르다.
- **핑퐁**: 비어 있을 때 동시 쓰기·읽기는 입력 데이터를 즉시 읽기 출력으로 전달하고 점유 수를 0으로 유지한다. full 상태에서 동시 읽기가 있으면 쓰기도 수락한다. 리셋 중 메모리 쓰기를 차단했다. 600회 연속 빈 버퍼 동시 전송/뱅크 순환 진단을 통과했다. 공식 테스트의 최종 empty 판정은 여전히 불일치한다. 샘플링 시점과 선행 자극을 포함한 추가 파형 분석이 필요하며, 테스트 문제로 확정하지 않았다. 이전의 리셋 테스트는 이번 실행에서 통과했으나 입력 미초기화와 무작위 선행 자극이 있어 이것만으로 해결을 확정하지 않는다.
- **나머지 5개**: 상충하는 동작 조건을 parameter로 분리했다. 기본값은 이전 원문 해석을 유지한다. 호환 설정만 바꾼 평가 제출본을 별도로 만들었다.
