# 즉시 오류 출력과 공식 평가 호환 수정본

최종 코드: vending_machine.sv

## 수정 및 검증

- 거스름돈: 배출과 반환 사이에 CHANGE_WAIT 한 클록을 추가해 공식 테스트의 관측 시점과 일치시켰습니다.
- 잘못된 ID: ITEM_SELECTION 상태에서 조합논리로 error를 즉시 표시합니다.
- 오류 유지: 잘못된 ID가 클록에 샘플링되면 INVALID_SELECTION 상태로 들어가 오류를 유지합니다. 후속 동전은 구매에 사용하지 않고 반환합니다. 취소 또는 리셋도 오류 상태를 해제할 수 있습니다.
- 동전 없이 오류가 사라져 공식 검사가 놓치는 문제를 해소했습니다. 입력이 클록 사이에서 잠깐 잘못됐다 복구되면 조합 오류만 표시하고 상태에는 저장하지 않습니다.
- 최종 공식 CVDP 평가: **1문제 통과**, 내부 pytest **10/10 통과**.
- 즉시 출력 독립 테스트: **15 assertions 통과**. 클록 이전 오류 발생, 일시적 입력 복구, 오류 유지, 환불 및 리셋을 확인합니다.

## 동작 계약의 차이

이 버전은 원문의 모든 조건을 그대로 구현한 버전은 아닙니다. 조합 즉시 오류와 공식 평가 호환을 함께 구현하기 위해 다음을 명시적으로 선택했습니다.

1. error는 잘못된 선택 이후 환불/취소까지 유지될 수 있으므로 정확히 한 클록 펄스가 아닙니다.
2. 거스름돈은 배출 바로 다음 클록이 아닌 대기 클록 이후에 나옵니다.
3. 잘못된 선택을 샘플링하면 유효한 ID로 바꾸는 것만으로는 거래를 재개하지 않으며 취소/환불/리셋이 필요합니다.

기존 spec_fixed의 32개 시나리오 테스트는 반환 시점과 오류 펄스 계약이 달라 이 버전의 통과 근거로 사용하지 않습니다. 독립 테스트 전체 통과 또는 원문 전체 충족을 주장하지 않습니다.

## 실행 기록

- r1: CHANGE_WAIT만 추가. 거스름돈 검사를 통과한 뒤 잘못된 선택 오류 검사에서 실패.
- r2: 오류 유지 상태 추가. enum 삼항식으로 시뮬레이터 컴파일 실패.
- r3: 명시적 if/else 상태 대입으로 수정. 공식 테스트 전체 통과.
