# 10문제 풀이 기록

- 작성자: 현재 대화의 Codex. 별도 외부 LLM API는 호출하지 않음.
- 첫 답안은 문제의 input.prompt 및 input.context로 작성. 공식 정답(output)이나 테스트 구현을 답안 작성에 사용하지 않음.
- first/는 최초 제출 원본. 테스트 후 수정본은 별도 폴더에 보존.
- local_import는 작성한 답안을 공식 평가기에 전달하는 어댑터 이름이며 생성 모델 이름이 아님.

## 첫 제출의 가정과 풀이

1. 우선순위 인코더: 낮은 비트부터 순회하며 활성 비트의 번호로 덮어써 최상위 비트를 선택.
2. 자판기: 문제에 상품별 가격표가 없어 ID 1~4의 가격을 5, 10, 15, 20으로 가정. coin_input=0 및 item_selected=0은 입력 없음으로 해석. 이 가정은 공식 테스트와 다를 수 있음.
3. FIR: 현재 샘플과 세 지연 샘플의 곱셈 합산 뒤 추가 레지스터로 총 4번째 수신 에지에 결과 출력. 16비트 출력은 하위 비트 사용.
4. AXI: 주소/데이터를 독립 저장하고 응답을 수신할 때까지 유지. 부분 쓰기는 원문대로 무시하며 ID는 0x00010001. done 상태는 래치 후 쓰기로 해제.
5. 클록 전환: 각 클록의 활성 조건을 두 플립플롭으로 전달하고 반대쪽 활성화를 상호 차단. 디지털 테스트 통과가 실제 실리콘의 CDC·글리치 안전성 보증은 아님.
6. MSHR: 빈 슬롯 탐색, 동일 주소 체인의 마지막 엔트리 연결, 완료 시 해제. 할당 결과는 1클록 지연으로 출력.
7. UART: 10비트 프레임과 분수 누산 보레이트 생성. 완료 신호 설명에 초기화와 일시정지 표현이 함께 있어 일시정지 후 이어 보내기로 해석.
8. Brent–Kung: 첫 그룹 generate/propagate의 잘못된 비트 참조를 수정하고 sum의 OR를 XOR로 수정.
9. 오디오 Lint: #1 지연 제거, 상수 폭 지정, 누산 식의 명시적 폭 정리, 미사용 파라미터 제거.
10. VGA: 수평·수직 타이밍 구간마다 중복된 카운터 증분/초기화를 공유. 기존 리셋과 출력 지연 유지.
